# Jira RAP Checker - Releases

Chrome extension so sánh instance trong file RAP (`.zip`) với Release Book trên Jira ticket. Repo này chỉ chứa file cài đặt (đã rút gọn và làm rối mã), không có mã nguồn.

## Cài đặt

1. Vào [Releases](../../releases), tải file `jira-rap-checker-v<version>.zip` mới nhất.
2. Giải nén ra một thư mục cố định (đừng xóa thư mục sau khi cài).
3. Mở `chrome://extensions`, bật **Developer mode**, bấm **Load unpacked**, chọn thư mục vừa giải nén.
4. Mở extension, nhập Base URL Jira, email và API token trong phần cấu hình. Token lưu mã hóa trong trình duyệt của bạn.

## Cập nhật

Tải bản mới, giải nén đè lên thư mục cũ, rồi bấm nút tải lại (reload) của extension trong `chrome://extensions`.
